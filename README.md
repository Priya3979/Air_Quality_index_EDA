# Air Quality Index (AQI) Exploratory Data Analysis

## Project Overview
This project focuses on analyzing air quality data from multiple Indian cities to understand pollutant levels, geographical variations, and pollution patterns across different states.

## Objectives
- Compare average pollutant levels across the top 20 most monitored cities.
- Analyze the distribution of average pollution levels across the top 10 monitored cities.
- Visualize geographical pollution hotspots using latitude and longitude.
- Identify the most frequently monitored pollutants.
- Compare average PM2.5 levels across Indian states.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis and Visualizations
1. City-wise pollutant comparison using a heatmap.
2. Pollution distribution analysis using a boxplot.
3. Geographical pollution hotspot visualization using a scatter plot.
4. Pollutant monitoring frequency using a bar chart.
5. State-wise PM2.5 comparison using a line plot.

## Dataset
Source: data.gov.in – Central Pollution Control Board (CPCB).

## Project Files
- `Air_Quality_Index_EDA.ipynb` – Python notebook containing data cleaning, exploratory analysis, and visualizations.

## Conclusion
The project explores variations in recorded air pollution levels across Indian cities and states using data analysis and visualization techniques.
